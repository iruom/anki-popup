# Anki Popup Android版 — 他のアプリの上で学習

[English](README.md) · [APKダウンロード](https://github.com/iruom/anki-popup/releases/tag/android-v0.3.0)

AnkiDroidのデッキから、表と裏を一緒に他のアプリの上へ表示するKotlin製アプリです。無彩色の小さなカードが、初期設定では30秒ごとに切り替わります。移動でき、通知には実行中の操作を残します。通知の音・振動は鳴らしません。

初版は**アルファ版**です。Android 9/API 28・Android 15/API 35相当のフレームワークテストを、架空のカードで実施しています。実機・実際のAnkiDroid連携・メーカー独自の省電力設定は未検証です。Google PlayではなくGitHubで配布します。

## 始め方

1. [AnkiDroid](https://ankidroid.org/)をインストールし、デッキを同期。一度開き、必要に応じて「設定 → 詳細」のAPIを有効にします。
2. Android版リリースから **AnkiPopupAndroid-0.3.0.apk** をダウンロード。開くと、ダウンロードに使ったアプリからのインストールを許可するようAndroidが案内します。
3. Anki Popupの「AnkiDroidに接続」を押して、連携権限を許可。
4. デッキ・表示間隔・必要なら表と裏のフィールド名を設定。空欄なら「表面/裏面」「Front/Back」「Expression/Meaning」などを認識し、なければ最初の2フィールドを使います。
5. 「他のアプリの上にカードを表示」をオンにして「開始」。Android設定でAnki Popupの「他のアプリの上に表示」を許可し、戻ってもう一度「開始」。Android 13以降では通知も許可してください。
6. 他のアプリを開いてもカードが表示されます。**タップで音声・長押しドラッグで移動・右スワイプで次へ・下スワイプで例文を開閉・上スワイプで次のカードまで隠す**。停止は通知か設定画面から操作できます。

**Android 8.0以降**に対応。AnkiDroidの標準パッケージが対象です。並列版・デバッグ版は未対応。AnkiDroidなしでも「サンプルカードで試す」で通知の動きを確認できます。

## 表示の仕組み

- フローティング表示には「他のアプリの上に表示」権限が必要です。スイッチをオフにすると以前の通知のみの表示になります。アクセシビリティ権限は不要。
- キーボードの入力先を奪わず、カードの外では元のアプリを操作できます。カードの中は操作のためタッチを受け取ります。
- 画面オフ・ロック中はカードを隠します。スクショを制限する `FLAG_SECURE` は外しました。表示中のカードもスクリーンショット・画面録画に写ります。
- 横幅220dpで、普段は単語と意味だけ。カード上のボタンはありません。小ささを保つため長文は省略し、例文は操作した時だけ開きます。
- アニメーションは80〜160ms。短く滑らかに切り替えます。Androidのアニメーション設定に従います。
- Android 12以降で対応端末・設定の場合、**カードの背景だけをぼかす**本物の背景ぼかしを使います。画面全体はぼかさず暗くもしません。非対応端末や省電力で無効になる場合は、読みやすい無彩色背景へ切り替えます。[Androidのぼかし仕様](https://source.android.com/docs/core/display/window-blurs)。
- 銀行アプリなど重ね表示を禁止するアプリや、権限ダイアログ・一部のシステム画面ではAndroid側が表示を抑止します。すべての画面への表示は保証できません。
- 「開始」したときだけ、常駐通知でセッションを実行します。
- 「隠す」は浮いているカード自体を一時的に消し、次の切り替えまで控えめな実行中メッセージにします。**タイマーはリセットしません。** 停止操作のための通知そのものは残ります。
- 一巡するまで同じノートを繰り返しません。裏表の反転カードは同じノートにまとめます。
- 「停止」で終了。端末起動時の自動開始や、プロセス終了後の自動再開はありません。
- スリープ中は更新が遅れる場合があります。再開時に通知を大量に積みません。省電力設定によって挙動が変わる場合があります。
- ロック画面には非公開扱いを指定し、代わりに一般的な実行中メッセージを用意しています。最終的な表示はAndroid・ユーザー設定に従います。
- ノートの文字フィールドを表示します。独自テンプレート・穴埋めの再現・画像・動画・MathJaxは未対応。長い文章は通知の表示量に制限されます。

## 音声

初期設定は、表の内容を**端末のオフライン音声で読み上げ**ます。読み上げ言語は `en-US` や `ja-JP` などで指定。対応するオフライン音声がなければ、インストールが必要なことを案内します。ネットワーク必須の音声には切り替えません。

保存済みのAnki音声を使いたい場合は、「音声フォルダを選択」でAndroidから読み取れるフォルダを指定してください。表・裏の `[sound:ファイル名]` と一致した音声を順に再生します。音声ファイルのコピーを入れたフォルダでも使えます。見つからない場合は端末の読み上げを使います。

AnkiDroid APIには保存済み音声を一般的に読み出すエンドポイントがありません。保存先がアプリ専用領域の場合など、Androidのフォルダ選択で指定できないことがあります。**AnkiDroidの連携権限だけでは録音へアクセスできません。** 広範囲のストレージ権限は要求せず、アクセス制限も回避しません。

音声はカードをタップするか、通知の音声操作を押したときだけ再生。非表示・停止・カード切り替えで再生を止めます。

## データと権限

AnkiDroidへの操作はデッキ・ノート・フィールド名の読み取りだけで、追加・更新・削除・復習評価は呼びません。AnkiDroidの権限名は読み書き共通ですが、このアプリは読み取りしか実装していません。

インターネット権限、分析、外部送信はありません。設定は端末内に保存し、クラウドバックアップや端末間転送の対象から除外します。音声フォルダの権限は選んだフォルダの読み取りのみ。「端末の読み上げを使う」でその保存済み権限を解除できます。カードや録音はAPKに含めません。

APKはプロジェクト専用のリリース鍵で署名しています。鍵はローカルだけに保存し、GitHubには公開していません。

## ビルド

JDK 17とAndroid SDK Platform 35／Build Tools 35.0.0が必要です。Android Studioでこのフォルダを開けます。

```sh
cd android
./gradlew testDebugUnitTest lintDebug assembleDebug assembleRelease
```

Debug版は開発用署名、Release版は未署名APKが生成されます。配布には自分の秘密鍵で署名してください。署名鍵・パスワードはコミットしないでください。

不具合報告には端末名・Android版・AnkiDroid版と入手元を添えてください。個人のカードや音声を送る必要はありません。
