# Anki Popup

**Android通知版のアルファ版も公開:** [APKダウンロード](https://github.com/iruom/anki-popup/releases/tag/android-v0.1.0) · [Android版の使い方](android/README.ja.md)。以下はMac版の説明です。

**作業中に、Ankiの単語が少しずつ目に入る。** 表と裏を一緒に表示する、Mac用の小さな常駐アプリです。

[English](README.md) · [ダウンロード](https://github.com/iruom/anki-popup/releases/latest) · [不具合の報告](https://github.com/iruom/anki-popup/issues/new/choose)

![架空のサンプルカードでの表示例](docs/preview.png)

Swift＋AppKit製。Ankiのローカルコレクションを読み取り、選んだデッキからランダムに表示します。Anki本体を起動したり、アドオンを入れたりする必要はありません。

## できること

- 表・裏を同時表示。例文やメモも表示できます。
- 背景はmacOSのVibrancy。カードを押しても作業中のアプリの入力フォーカスを奪いません。
- カード本文または▶︎を押すと、保存されている音声を再生。
- 上部をドラッグして移動。次のカードや再起動後も位置を引き継ぎます。
- ×で一時的に隠す。**次の表示時刻になったら、新しいカードが出ます。** タイマーはリセットしません。
- 初期設定は30秒ごと。5〜3600秒で変更できます。
- プロファイル、デッキ、表と裏のフィールドを選択。子デッキも対象です。
- 一巡するまで同じノートを繰り返しません。
- メニューバーの「Anki」から一時停止・次のカード・設定・終了。
- 日本語・英語のUIに対応。macOSの言語に合わせて切り替わります。

復習の評価やAnkiの学習スケジュールは変更しません。作業しながら学習内容に触れるためのアプリです。

## インストール

**macOS 13 Ventura以降／Apple Silicon・Intel対応。** Anki Desktopでカードを作成・同期しておいてください。

1. [Releases](https://github.com/iruom/anki-popup/releases/latest)から `AnkiPopup-1.0.0-universal.zip` をダウンロード。
2. 解凍し、**Anki Popup.app** をアプリケーションフォルダへ移動。
3. 起動してプロファイルとデッキを選び、「保存して開始」。
4. メニューバーの **Anki** から、いつでも設定を変更できます。

初版はアドホック署名で、Developer ID署名・Appleの公証はありません。ダウンロードしたアプリがmacOSに止められることがあります。このプロジェクトを信頼できる場合に限り、一度開こうとしたあと **システム設定 → プライバシーとセキュリティ → このまま開く** を使ってください。Gatekeeperを無効にする必要はありません。[Appleの説明](https://support.apple.com/ja-jp/guide/mac-help/mh40616/mac)。ソースからのビルドも可能です。

ZIPのSHA-256は、リリースの `SHA256SUMS.txt` と比較できます。

## 設定と操作

| 設定 | 内容 |
| --- | --- |
| プロファイル | 通常のAnki保存先から自動検出。「参照」で別の `collection.anki2` も選べます。 |
| デッキ | 全デッキ、または選んだデッキと子デッキ。 |
| 表・裏のフィールド | 「自動」は表面/裏面、Front/Back、Expression/Meaningなどを認識し、該当しない場合は最初の2フィールドを使います。特殊な構成なら明示的に選んでください。 |
| 例文・メモ | よく使われる例文・訳・メモのフィールドを追加表示。 |
| マウス操作を通す | カードの背後を操作できます。このモードではカード上の音声・ドラッグ・×は無効になります。メニューバーから隠す・位置変更などができます。 |

×を押した時点で残り10秒なら、約10秒後に次のカードが表示されます。音声は選択した表・裏の `[sound:filename]` を順番に再生。自動再生はしません。再クリックで最初から再生し、非表示・一時停止・カード切り替えで停止します。

## 対応範囲

Ankiの**ノートのフィールドを直接表示するアプリ**です。カードテンプレート自体の再現ではありません。表・裏に使う2フィールド以上のある、文字主体のノートが対象です。裏表の反転カードは、同じノートとしてまとめます。

穴埋め形式（cloze）の表示、独自のテンプレート処理、画像・動画・MathJax・AnkiのCSSは未対応。HTMLは文字に変換します。設定画面にもこの制限を表示しています。

現在のSQLiteテーブル形式と旧JSONメタデータ形式に対応。Anki内部の形式を利用するため、将来のAnki更新で修正が必要になる場合があります。実コレクションと架空の新旧形式データで検証済み。Intel用はクロスコンパイルしており、実際のUI動作はApple Siliconで確認しています。

Ankiで編集・同期したあと、設定画面で「保存して開始」を押すと再読み込みできます。移動位置はカードの左上を基準に保ち、接続中の画面内に収まるように調整します。

## プライバシー

コレクションは**読み取り専用**で開き、カード・学習履歴を書き換えません。ネットワーク通信、分析、アカウント作成、外部アップロードはありません。音声はコレクションのメディアフォルダ内のファイルだけを使います。保存先・選択デッキ・設定・表示位置はmacOSのUserDefaultsに保存します。カードや音声は公開リポジトリや配布アプリに含めていません。

Anki公式とは独立したソフトウェアです。

## ソースからビルド

Xcode Command Line Tools（`xcode-select --install`）またはXcodeを入れてから:

```sh
git clone https://github.com/iruom/anki-popup.git
cd anki-popup
./scripts/test.sh
./scripts/build.sh
open "dist/Anki Popup.app"
```

追加のライブラリは不要です。`dist/` にApple Silicon・Intel両対応アプリ、ZIP、チェックサムが生成されます。テストは架空のデータだけを使います。

不具合報告にはOS・Anki・アプリのバージョンと、フィールド名や架空の再現例を添えてください。個人のコレクションや音声のアップロードは不要です。
